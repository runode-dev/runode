## 中文

### 新功能

- **远程访问可选监听哪个网络**：新配置项 `remote-access-address`，配对页的「网络」下拉框和设置页的远程访问一页都能选。默认只在局域网里连；选 0.0.0.0 才同时允许经互联网连接；选某块网卡的地址时只在那个地址上监听，Bonjour 也只在那块网卡上公布这台电脑。**升级后要在外网连这台电脑的，需要把网络改选成 0.0.0.0。**

### 修复

- 锁屏、窗口被盖住或最小化时，在手机上新开的终端会马上启动 shell，不再一直空白、打字没反应。
- 配对页选了这台电脑没有的地址、配对失败后，换网络或改名字时会自己重新生成二维码，不用手点重试。

### 性能

- agent 干活时，标题栏和侧栏里的转圈动一格不再重新排版整条栏，转圈也动得慢一些；只有后台 agent 在跑时，界面进程的 CPU 占用从约 3% 降到 1% 以下。

## English

### Features

- **Choose which network remote access listens on**: A new `remote-access-address` setting, available from the Network menu on the pairing page and the Remote Access page in Settings. By default only devices on the local network can connect; choose 0.0.0.0 to also allow connections over the internet; choose a specific interface address to listen only on that address, and Bonjour then advertises this computer only on that interface. **If you connect to this computer from outside your network, change the network to 0.0.0.0 after upgrading.**

### Fixes

- Terminals opened from the phone now start their shell right away while the screen is locked or the window is covered or minimized, instead of staying blank and ignoring typing.
- After pairing fails because the selected address doesn't exist on this computer, switching networks or renaming now regenerates the QR code without having to click Retry.

### Performance

- While an agent is working, each spinner step in the title bar and sidebar no longer re-lays out the whole bar, and spinners animate more slowly; with only background agents running, the UI process's CPU usage drops from about 3% to under 1%.
