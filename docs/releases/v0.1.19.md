## 中文

### 新功能

- **手机上直接起 agent**：iPhone app 新开终端时，除了普通终端，还能直接挑电脑上装着的 Claude、Codex、Pi 等 agent，开好新标签就跑起来。首页、电脑页的「新建」、工作区标题的「+」和长按菜单都能挑。
- 文件树的更多菜单只列本机装着的编辑器（VS Code、Cursor、Zed），没装的不再列出来。

### 修复

- Mac 上给远程桌面打开辅助功能权限后，观看端不用重连就能操作，不再一直显示「只能看」。
- 另一台电脑经 SSH 连着这台电脑的终端时，在这台电脑上打开不同版本的 Runode，会和那边共用终端，不再误报旧版本还开着、请你退出。
- 在 macOS 虚拟机里打字不再卡顿，字不会过一会儿才一起出来。
- 侧栏、文件树里就地改名时，点空白处也能结束编辑。
- 远程桌面查授权卡住时不再拖住锁屏状态的上报；一直查不成时日志只记一次，不再每秒刷屏。

### 性能

- 另一台电脑经 SSH 连着旧版本的终端宿主时，打开新版 Runode 不再反复拉起接班的宿主进程。

## English

### Features

- **Start agents from your phone**: When opening a new terminal in the iPhone app, you can now pick an agent installed on the computer, such as Claude, Codex or Pi, besides a plain terminal, and it starts in the new tab. The choice is available from the home page, the computer page's New button, a workspace title's + button and its long-press menu.
- The file tree's More menu now lists only the editors installed on this computer (VS Code, Cursor, Zed).

### Fixes

- After turning on Accessibility for remote desktop on a Mac, the viewer can control the screen without reconnecting instead of staying view-only.
- When another computer is connected to this computer's terminals over SSH, opening a different version of Runode here now shares the terminals with it instead of wrongly reporting that an old version is still running and asking you to quit it.
- Typing no longer lags in a macOS virtual machine, where characters used to appear in bursts.
- Inline renaming in the sidebar and file tree now ends when you click empty space.
- A stuck permission check no longer delays remote desktop's lock-screen updates, and a check that keeps failing is logged once instead of every second.

### Performance

- When another computer is connected over SSH to an older terminal host, opening the new Runode no longer repeatedly launches replacement host processes.
