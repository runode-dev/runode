## 中文

### 新功能

- **GitHub Actions 页**：右侧面板新增一页，经本机装的 gh 看工作流运行、job、step 和日志，触发工作流，管理 secret 和 variable；固定的工作流显示在状态栏左边。
- **分屏折叠**：卡片样式下，标签里的分屏可以折叠成标题条、排到终端区底部，点一下回到原位（默认 ctrl+cmd+-）；agent 用 `runode open` 开的分屏默认折叠，设置页「Agents」里可以关。
- **Runode Dark、Runode Light 主题**：默认配色做成内置主题，另加一套浅色的，两个排在主题列表最前。
- **最低对比度**：新配置项 `minimum-contrast`（默认 3），字和底色对比度不够时自动调亮或调暗，深色配色的程序开在浅色主题里也看得清。
- 终端向程序报告主题是深色还是浅色，换主题时通知订阅的程序，Claude Code 的 Auto 主题这类会跟着切换。
- 界面字号统一由 `ui-font-size` 决定，整个界面一起等比缩放；Git 面板的字号跟着 `file-tree-font-size`。
- Git 面板可以藏起子模块和其他工作树。
- zsh 的 Tab 绑了 fzf-tab 这类补全时交给它，不再被 Runode 的补全接管。
- 手机上 agent 等回答的提醒改成普通推送通知，点开直接跳到那个会话。
- 侧栏底部加了设置按钮；文件树和 Git 面板认得 Dart 文件。
- 去掉了上一版加的「决策模型」页。

### 修复

- 显示器睡着或切到别的 Space 时，agent 停下照样提醒。
- 窗口挪到别的屏幕后，重启时回到挪过去的那块屏。
- 打开带表格的 Markdown 预览不再崩溃。
- 关掉模拟器画面和预览图片后显存会释放。
- 界面字号调大后，几处控件不再装不下字或压到别处。
- 手机 App 在后台时点开通知不再闪退，进后台后会话列表正确显示为断开；重连被拒时过一会儿自动再连。
- GitHub Actions 页里等批准的运行不再当成没跑完。

### 性能

- 窗口空闲时停掉显示刷新，不再每秒唤醒几十上百次；窗口看不见时终端也不再更新界面那一份。
- 后台的轮询大多改成按事件触发或拉长间隔：配置文件、远程访问、推送、配对设备、状态栏和侧栏分支徽标都是。
- 内存占用更低：语法高亮空闲一分钟后释放，颜色缓存、网络图片、手机端回滚历史和输出积压都有了上限。
- 手机看终端时让 Wi-Fi 保持清醒，打字回显不再卡顿；连电脑时同时试 Bonjour 和记着的地址，连得更快。
- 按文件名和内容找文件更快，打字时不再每个字都搜一遍。

## English

### Features

- **GitHub Actions page**: a new right-panel page uses your installed gh to show workflow runs, jobs, steps and logs, trigger workflows, and manage secrets and variables; pinned workflows appear on the left of the status bar.
- **Folding panes**: in the card style, panes in a tab can fold into a title strip at the bottom of the terminal area and come back with one click (ctrl+cmd+- by default); panes agents open with `runode open` are folded by default, which can be turned off under Settings › Agents.
- **Runode Dark and Runode Light themes**: the default colors are now a built-in theme, joined by a light one, both at the top of the theme list.
- **Minimum contrast**: the new `minimum-contrast` option (default 3) lightens or darkens text that is too close to its background, so programs with dark color schemes stay readable in a light theme.
- The terminal tells programs whether the theme is dark or light and notifies subscribers when it changes, so things like Claude Code's Auto theme follow along.
- All UI text sizes now derive from `ui-font-size` and scale together; the Git panel follows `file-tree-font-size`.
- The Git panel can hide submodules and other worktrees.
- When zsh's Tab is bound to a completion like fzf-tab, Runode leaves it to that instead of taking over.
- On the phone, "agent is waiting for an answer" alerts are now regular push notifications that open the session when tapped.
- A Settings button at the bottom of the sidebar; Dart files are recognized in the file tree and Git panel.
- Removed the Decision model page added in the previous release.

### Fixes

- Agents stopping still trigger an alert while the display sleeps or another Space is active.
- A window moved to another display reopens on that display after a restart.
- Opening a Markdown preview containing a table no longer crashes.
- Closing the simulator view or a preview image now frees its GPU memory.
- With a larger UI font size, several controls no longer clip their text or overlap others.
- Tapping a notification while the phone app is in the background no longer crashes it; the session list shows as disconnected in the background, and a rejected reconnect retries after a moment.
- Runs waiting for approval on the GitHub Actions page are no longer treated as unfinished.

### Performance

- Idle windows stop display refresh instead of waking the app dozens of times a second, and hidden windows stop updating their terminals' display copy.
- Most background polling is now event-driven or less frequent: config files, remote access, push, paired devices, the status bar and sidebar branch badges.
- Lower memory use: syntax highlighting is released after a minute idle, and color caches, web images, phone scrollback and output backlogs are capped.
- The phone keeps Wi-Fi awake while viewing a terminal, so typing echoes without lag, and connects to the computer via Bonjour and remembered addresses at once.
- Finding files by name or content is faster and no longer searches on every keystroke.
