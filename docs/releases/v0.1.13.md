## 中文

### 新功能

- **Windows 上能用桌面 app、宿主和命令行**：远程桌面也支持 Windows，桌面 app 带上图标和窗口按钮。Windows 和 Linux 上的默认快捷键不再用 Win 键。
- **离线语音输入**：桌面和手机都能把话转成文字，识别在本机用模型完成，也可以交给云端识别、用大模型润色；识别放在单独的子进程里，闲了就退出，设置里语音输入有单独一页。
- **手机跨网络连到电脑**：不在同一个网络时经 iroh 按公钥连过来，打洞直连，打不通走中继。手机端的远程桌面页能切屏，电脑锁屏时用存着的密码解锁。
- **看板**：新建任务改成单独一页，建好了才露出看板；卡片显示任务分支上的 PR，能一键推送并开 PR，PR 合并后任务自动完成，开着 PR 的标「待评审」；新开的工作树先跑项目配的 setup 命令。
- **预览栏能编辑文本文件并保存**，编辑器带语法高亮；Markdown 里引用的 GIF 只显示第一帧，大录屏不再因占内存过大而显示不出来。
- 差异视图的块头加上「交给 agent」，把这块改动贴进当前终端。
- 窗格恢复时接回 Claude Code 的对话。
- 分屏能挪到别的标签或工作区，两个分屏能对调。
- 命令菜单里 Makefile 和 package.json 的命令默认收起（设置里可关），从菜单跑命令时新分屏折叠起来。
- 程序用 OSC 9、OSC 777 要求的桌面通知转成系统通知。
- 官方 iOS App 的推送改用中转句柄，电脑拿不到手机的 device token。

### 修复

- 新终端不再继承外层终端和 Claude Code 的会话变量。
- 挪分屏时焦点不再跳走，卡片样式下记下的分屏位置不再偏一个分屏高。
- 设置页写回的值等于默认值时删掉这一行，不再留着恢复按钮；文件管理器和回收站按系统叫对名字。
- 看板不再被同名分支以前合并的 PR 误标完成；恢复终端时续接对话更可靠。
- 手机远程桌面：解锁不再误删存着的密码，退到后台时断开，静止时也能补出关键帧，断线时松开按着的鼠标键，取消拨号时马上返回。
- 宿主平常单独一个进程跑，升级接手后的终端照样连得上局域网。
- Windows 上关终端不再可能卡死。

## English

### Features

- **The desktop app, host and command line run on Windows**: remote desktop supports Windows too, and the app has an icon and window buttons. Default shortcuts on Windows and Linux no longer use the Win key.
- **Offline voice input**: dictate on your Mac or your phone; speech is recognized locally with a model, with optional cloud recognition and LLM polishing. Recognition runs in a separate process that exits when idle, and Settings has a page for voice input.
- **Phone connects across networks**: when it isn't on the same network, it reaches your computer through iroh by public key, punching a direct path and falling back to a relay. The phone's remote desktop page can switch displays and unlock a locked screen with a saved password.
- **Kanban**: new tasks have a page of their own and the board shows once one is created; cards show the PR on the task's branch with one-click push and open PR, a task whose PR is merged is marked done, and tasks with an open PR are marked "In review"; a fresh worktree first runs the project's setup command.
- **The preview panel can edit and save text files**, with syntax highlighting in the editor; GIFs in Markdown show their first frame, so large screen recordings no longer fail to appear for using too much memory.
- Diff hunks have "Send to agent", which pastes that change into the current terminal.
- Restored panes reconnect to the Claude Code conversation.
- Splits can be moved to another tab or workspace, and two splits can be swapped.
- Makefile and package.json commands in the command menu are collapsed by default (can be turned off in Settings), and a split opened by running a command from the menu starts collapsed.
- Desktop notifications requested with OSC 9 and OSC 777 become system notifications.
- Push in the official iOS app uses relay handles, so your computer never gets the phone's device token.

### Fixes

- New terminals no longer inherit the session variables of the outer terminal and Claude Code.
- Moving a split no longer makes focus jump away, and split positions remembered in the card style are no longer one split-height off.
- A setting written back at its default value removes its line instead of leaving a reset button; the file manager and trash are named correctly per system.
- Kanban no longer marks a task done because of a PR merged earlier on a same-named branch; resuming a conversation when restoring a terminal is more reliable.
- Phone remote desktop: unlocking no longer deletes the saved password, the connection drops when the app goes to the background, keyframes are produced when the screen is still, held mouse buttons are released on disconnect, and cancelling a dial returns right away.
- The host normally runs as a separate process, so terminals taken over after an upgrade can still reach the local network.
- Closing a terminal on Windows can no longer hang.
