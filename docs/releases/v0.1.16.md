## 中文

### 新功能

- **终端显示图片**：支持 Kitty 图形协议，`kitten icat` 这类程序输出的图片和动图在桌面和手机上都能看到；宿主升级接手时图片不丢。
- **手机远程桌面的触控板模式**：右上角按钮在触屏和触控板之间切换。触控板模式下单指移动光标，点按是左键，双指点按是右键，长按后拖动是按住左键拖。
- **⌘⌥K 把路径打进终端**：在文件树、预览栏和 Git 面板里按 ⌘⌥K，把当前文件的路径打进终端，方便交给 agent；预览里选着行时带上行号，写成「路径:首行-末行」。

### 修复

- Git 面板里点文件看 diff 不再抢走提交说明框的焦点，写到一半的说明不会丢字。
- Git 面板里按 Esc 先关菜单，没有菜单时把焦点交回终端。
- 手机上平滑滚动时，画面中间不再漏出一条背景色的细缝。

## English

### Features

- **Images in the terminal**: the Kitty graphics protocol is supported, so images and animations from programs like `kitten icat` show on the desktop and on the phone, and they survive a host upgrade.
- **Trackpad mode for phone remote desktop**: the button at the top right switches between touch and trackpad. In trackpad mode one finger moves the cursor, a tap is a left click, a two-finger tap is a right click, and a long press then drag holds the left button.
- **⌘⌥K types a path into the terminal**: in the file tree, the preview pane and the Git panel, ⌘⌥K types the current file's path into the terminal, ready to hand to an agent; with lines selected in the preview it adds them as `path:first-last`.

### Fixes

- Clicking a file in the Git panel to see its diff no longer takes focus away from the commit message box, so a half-written message no longer loses keystrokes.
- Esc in the Git panel closes its menu first, and otherwise returns focus to the terminal.
- Smooth scrolling on the phone no longer shows a thin background-colored seam across the screen.
