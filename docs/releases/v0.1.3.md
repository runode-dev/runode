## 中文

### 新功能

- **右侧面板合一**：文件树和 Git 面板合成一个面板，顶上标签切换，标题栏只留一个开关。
- **文件树搜索**：按文件名或内容搜索，支持区分大小写、全字匹配、正则和包含、排除文件，结果可排成列表或树，搜索设置随窗口恢复；文件树的「更多」菜单加了显示点文件。
- **项目命令**：命令菜单移到标题栏的运行按钮（`⌘⇧R`），按文件分组可折叠，会记住每个工作区上次跑的命令；可以自己添加、编辑、删除命令，存在 `~/.runode/tasks.json`，分「所有目录通用」和「当前项目」两种。
- **AI 写提交说明**：Git 面板提交框右上角的 ✨ 让本机的 AI 编程 agent 照最近提交的写法起草说明，可选 agent 或自定义命令，预设可存为当前仓库或所有仓库的。
- **预览栏**：加了自动换行和放大两个按钮。
- **侧栏**：workspace 行显示 GitHub 头像（不在 GitHub 上时是 git 图标）和当前分支；快捷键提示只在按住修饰键时显示。
- **Git 面板**：改动的文件行显示加减行数；默认快捷键改成 `⌘⇧G`。
- **状态栏**：可以整条隐藏，也可以只隐藏其中几块。
- **命令补全**：认得 `~/.runode/completions/<命令名>.json` 里自己写的规格。
- **卡片样式**：标签和分屏标题显示 agent 自己设的标题；标题栏不再显示电脑名，配对过的设备改在手机端引导页查看和撤销，设置里的「配对…」直接跳到引导页的配对一步。
- **手机端**：支持英文、简体中文、繁体中文，跟随系统语言。
- **命令行**：`runode send --wait` 发给 agent 后 10 秒内既没干活也没提问就报错退出，不再一直等到超时。
- 设置窗口里开着通知、系统却拒绝了 Runode 发通知时给出提示和打开通知设置的按钮。

### 修复

- 预览栏放大时切标签、切 workspace 或新开标签，现在先还原放大；原来打的字会进到被盖住的终端。
- 文件树搜索在文件树刷新后保留选中行和滚动位置；`*.{ts,tsx}` 这样的花括号现在能搜到；不再列出已删除的文件。
- 源代码管理里鼠标移到行上就崩溃的问题；行尾按钮不再挤占文件名。
- AI 写提交说明的 agent 超时后整组进程一起结束，不再留着真正的 agent 占住仓库。
- 自己加的项目命令不再包成 `(cd .. && 命令)`，在 fish 里命令行带 `#` 注释时会卡在续行上。
- 退出确认框选「留在后台」时，标题和说明不再自相矛盾。
- 设置窗口里配置值已是默认值时不再显示恢复按钮；APNs 密钥文件的说明讲清楚了什么时候才需要填。
- 用户的命令规格解析失败时不再每按一次键重读、重报警告。
- 终端在 origin mode 下重放后光标位置不对（升级 libghostty）。
- 手机端英文、繁体界面里漏翻的两处。

### 注意

- 配置、数据和缓存从 `~/.config/runode` 挪到了 `~/.runode`，不再跟随 `XDG_CONFIG_HOME`；升级后需要把旧目录里的文件手动挪过去。

## English

### Features

- **One right-hand panel**: the file tree and Git panel are merged into one panel with tabs on top, and a single toggle in the title bar.
- **File tree search**: search by file name or content, with case-sensitive, whole-word, regex, and include/exclude file options; results can be a list or a tree, and the search settings are restored with the window. The file tree's "More" menu gains Show Dotfiles.
- **Project commands**: the command menu moves to the run button in the title bar (`⌘⇧R`), grouped by file with collapsible groups, and remembers the last command run in each workspace. You can add, edit and delete your own commands, stored in `~/.runode/tasks.json`, either for all directories or for the current project.
- **AI commit messages**: the ✨ button in the Git panel's commit box has a local AI coding agent draft a message in the style of your recent commits. Pick an agent or use a custom command, and save the preset for this repository or all repositories.
- **Preview pane**: new word-wrap and maximize buttons.
- **Sidebar**: workspace rows show the GitHub avatar (a git icon outside GitHub) and the current branch; shortcut hints appear only while the modifier key is held.
- **Git panel**: changed file rows show added/removed line counts; the default shortcut is now `⌘⇧G`.
- **Status bar**: hide the whole bar, or just some of its blocks.
- **Command completion**: reads your own specs from `~/.runode/completions/<command>.json`.
- **Card style**: tabs and split titles show the title the agent set itself; the title bar no longer shows the computer name, paired devices are managed on the mobile onboarding page, and "Pair…" in Settings jumps to the pairing step there.
- **Mobile app**: English, Simplified Chinese and Traditional Chinese, following the system language.
- **Command line**: `runode send --wait` now exits with an error if the agent neither starts working nor asks a question within 10 seconds, instead of waiting until the timeout.
- The settings window shows a notice, with a button to open notification settings, when notifications are on but macOS has denied Runode permission.

### Fixes

- Switching tabs or workspaces, or opening a new tab, while the preview pane is maximized now restores it first; typed text used to go into the hidden terminal.
- File tree search keeps the selected row and scroll position when the tree reloads; `*.{ts,tsx}`-style braces now match; deleted files are no longer listed.
- Fixed a crash when the mouse moved onto a row in Source Control; row-end buttons no longer squeeze file names.
- The AI commit message agent is now stopped as a whole process group on timeout, so the real agent no longer keeps the repository busy.
- Your own project commands are no longer wrapped as `(cd .. && command)`, which left fish stuck on a continuation line when the command ended with a `#` comment.
- The quit confirmation dialog no longer contradicts itself when offering to keep things running in the background.
- The settings window no longer shows a restore button when the config already holds the default value; the APNs key file description now says when you actually need it.
- A user command spec that fails to parse is no longer re-read and re-reported on every keystroke.
- Wrong cursor position after replay in origin mode (libghostty update).
- Two strings missed in the mobile app's English and Traditional Chinese UIs.

### Note

- Config, data and cache moved from `~/.config/runode` to `~/.runode` and no longer follow `XDG_CONFIG_HOME`; after upgrading, move your files from the old directory by hand.
