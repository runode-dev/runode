## 中文

### 新功能

- **Linux 桌面版**：Linux（x86_64 和 aarch64）上有了带界面的桌面 app，发布 AppImage、deb 和 rpm 三种包。在图形界面的终端里运行安装脚本，装的是 AppImage，会加进应用菜单，之后自己更新（需要系统装有 FUSE，即 `fuse3`）；deb、rpm 交给 apt、dnf 管理，不自己更新。在没有桌面的服务器上，安装脚本照旧只装命令行和终端宿主。从 AppImage 打开的 Runode 里，终端照样能直接敲 `runode`。

### 修复

- 连 SSH 主机时，如果 runode 在远端跑不起来，现在会报出真正的原因（比如缺了哪个动态库），不再一律说可能是 home 目录挂成了 noexec。

## English

### Features

- **Linux desktop app**: Linux (x86_64 and aarch64) now has the desktop app with its UI, released as an AppImage, a deb and an rpm. Running the install script in a terminal in a graphical session installs the AppImage, adds it to the application menu and keeps it up to date (FUSE is required, i.e. `fuse3`). The deb and rpm are managed by apt and dnf and don't update themselves. On a server without a desktop, the install script still installs just the command line and the terminal host. In Runode opened from the AppImage, terminals can still run `runode` directly.

### Fixes

- When runode can't run on an SSH host, the error now says why (for example which shared library is missing) instead of always suggesting the home directory may be mounted noexec.
