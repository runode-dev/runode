## 中文

### 新功能

- **登录时自启**：命令行 `runode service` 和设置窗口里的开关，登录时自动拉起桌面 app 或无界面的宿主。
- **命令行 help**：拆成总览加每条命令一页。
- **检查更新**：手动检查查到新版本时先问，选了再下载，菜单里显示检查和下载的进度。
- `runode remote pair` 在远程访问没开时自己写上 `remote-access = true`。
- curl 安装下载安装包时显示进度。
- 命令补全：claude、codex 的规格对齐最新帮助，新增 gemini、opencode、qwen、amp、cline、kilo 的规格。

### 修复

- curl 安装默认把命令行装进 PATH 上能写的 bin 目录。
- 发版包里补上了应用图标（之前的版本没有）：图标改用提交进仓库的预编译产物，不再依赖 CI 上不稳定的 actool。
- 远程访问门禁：按来源限并发，读失败也计入限速，错口令不再作废配对，IPv6 按 /64 限速；生产环境 APNs 频道端口改为 2196。
- 自启服务只在崩溃后重启，装和卸都不再停掉正在跑的宿主。
- 宿主连不上时开窗不再 panic；回退到进程内宿主后补开远程访问监听；清理旧的屏幕转存文件。
- 终端：OSC 7501 报状态时宽限期过后宿主不再空转；bash 的 `PROMPT_COMMAND` 以分号结尾时不再语法错误；终端查询的应答队列加上限。
- 提示符里有全角空格等空白时高亮不再死循环；未跟踪大文件的 diff 不再整份读进内存；补全在大目录里先按名字筛再截断。
- iOS：断线后新开终端按钮不再卡灰；重连更新地址时不再把改过的电脑名字改回去。
- 配置里 `font-size` 为 0、负数或 NaN 时跳过、用默认字号。

## English

### Features

- **Start at login**: `runode service` on the command line and a switch in the settings window launch the desktop app or the headless host when you log in.
- **Command-line help**: split into an overview plus one page per command.
- **Check for updates**: a manual check that finds a new version now asks first and downloads only if you agree; the menu shows check and download progress.
- `runode remote pair` now writes `remote-access = true` itself when remote access is off.
- The curl installer shows download progress.
- Command completion: claude and codex specs match their latest help, and new specs for gemini, opencode, qwen, amp, cline and kilo.

### Fixes

- The curl installer now installs the command line into a writable bin directory on your PATH by default.
- Release packages now include the app icon (earlier versions had none): the icon is a precompiled artifact checked into the repo instead of being built by the unreliable actool on CI.
- Remote-access gate: concurrency is limited per source, read failures count toward rate limiting, a wrong pairing code no longer invalidates the pairing, IPv6 is rate-limited per /64, and the production APNs channel port is now 2196.
- The login service restarts only after a crash, and installing or removing it no longer stops a running host.
- No panic when the host cannot be reached while opening a window; remote-access listening is started after falling back to an in-process host; stale screen dump files are cleaned up.
- Terminal: the host no longer spins after the grace period when OSC 7501 reports status; a `PROMPT_COMMAND` ending in a semicolon no longer breaks bash; the terminal-query reply queue is capped.
- Prompt highlighting no longer loops forever on full-width spaces and similar whitespace; diffs of large untracked files are no longer read into memory whole; completion filters large directories by name before truncating.
- iOS: the new-terminal button no longer stays greyed out after a disconnect; reconnecting no longer resets a renamed computer name.
- A `font-size` of 0, a negative number or NaN in the config is ignored and the default size is used.
