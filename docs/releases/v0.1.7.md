## 中文

### 新功能

- **决策模型页**：设置里新增「决策模型」一页，管理另外安装的 runode-infer：看它装没装、在不在跑，启动和停止；填托管 API 的密钥（交给 runode-infer 保存，Runode 自己不存）；下载和删除本机模型，关掉设置页也接着下。
- **右侧面板按工作区记**：每个工作区各自记着右侧显示文件树、Git、模拟器还是收着，模拟器页选的设备也各记一台，切工作区时跟着换，重启后各自恢复。
- **Git 图表区分推没推**：照 VSCode 的样子，当前分支已经推上去的部分是蓝色，还没推的提交往下换成紫色，远端分支的标签也描紫色。
- `runode send` 认 tmux send-keys 的写法：文字最后单独一个 `Enter` 是按回车，和 `--enter` 一样；要打出 Enter 这个词，放在 `--` 后面。

### 修复

- 升级后接手过来的终端照样连得上局域网，不再报 No route to host，也不再弹本地网络的权限框。
- 程序改了终端的默认前景色、背景色时，侧栏、标题栏、面板和状态栏马上跟着换色，不再停在旧颜色上。
- 模拟器页连接到一半就收起时，不再在后台留着一个一直推画面的 mobilecli。
- 决策模型页标出这台 Mac 跑不了的模型，出错原因能被辅助工具读到。

### 性能

- 终端有输出时不再整个窗口重画：侧栏、标题栏、预览栏、右侧面板和状态栏没变时照搬上一帧，agent 的转圈动画只重画它自己那一块。

## English

### Features

- **Decision model page**: a new Settings page manages a separately installed runode-infer: see whether it is installed and running, start and stop it, enter hosted API keys (handed to runode-infer; Runode does not store them), and download or delete local models, with downloads continuing after Settings is closed.
- **Right panel per workspace**: each workspace remembers whether the right panel shows Files, Git, the simulator or nothing, and which simulator device it uses; switching workspaces switches them, and they are restored after a restart.
- **Pushed vs. unpushed in the Git graph**: like VSCode, the pushed part of the current branch is blue, unpushed commits below it turn purple, and remote branch labels are outlined in purple.
- `runode send` accepts the tmux send-keys form: a lone trailing `Enter` presses Return, the same as `--enter`; put it after `--` to type the word Enter.

### Fixes

- Terminals handed over during an upgrade can still reach the local network: no more No route to host, and no new local network permission prompt.
- When a program changes the terminal's default foreground or background color, the sidebar, title bar, panels and status bar follow immediately instead of keeping the old color.
- Closing the simulator page while it is still connecting no longer leaves a mobilecli streaming in the background.
- The decision model page marks models this Mac cannot run, and its error messages are readable by assistive tools.

### Performance

- Terminal output no longer redraws the whole window: the sidebar, title bar, preview bar, right panel and status bar reuse the previous frame when unchanged, and the agent spinner redraws only its own area.
