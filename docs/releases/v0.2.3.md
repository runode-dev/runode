## 中文

### 新功能

- **预览栏里直接改代码**：文本文件打开就是代码编辑器，接上语言服务器后有补全、悬停说明、跳到定义和诊断；按 git 仓库分开起服务器，SSH 主机上的项目也有，服务器跑在那台主机上；⌘D 加选下一处相同的文字。
- **预览和终端并排**：把文件标签拖到终端区边上，预览就停靠在那一侧；拖回标题栏或侧栏开关上又盖满终端区。
- diff 标签的标题栏加了「编辑文件」按钮，按下打开这个文件，编辑器把 diff 里正看的那一行滚到正中；从搜索结果这类入口跳到某一行时，那一行也滚到正中。
- 从访达拖文件进来、用「打开方式」都能在编辑器里打开；Linux 和 Windows 上也能用「打开方式」和右键菜单在 Runode 里打开文件和文件夹。
- **侧栏重新排过**：任务挪到搜索框下面，底部只留手机和设置一行；单工作区的项目并成一行，主机分组层级更清楚；项目名前显示项目图标，右键能换成本地图片，没开终端时调淡，等回答时角上闪圆点；agent 图标放到分支名左侧。
- agent 做完时也给手机推通知。
- 提交图的右键菜单加了撤销提交和撤销推送。

### 修复

- 侧栏不在当前的项目、状态栏在没读 git 状态的工作区，也显示没推的提交数；切换工作区时把那一行滚进视野；各行的间距和对齐理顺。
- 等回答的推送正文只留问题，不带之前的输出和标签条。
- 手机断线重连后，终端尺寸接着按手机屏幕定。
- 外部语音转写打进终端的文字不再变成 a。
- 远端主机终端里的中文文件名不再印成转义的字节。
- 给 AI 写提交说明时，改动里未跟踪的文件名不再带转义。
- Windows 上按 PATH 找 curl.exe 时跳过空段和相对段；PowerShell 单引号字符串里的弯引号也写两遍。
- 新宿主撞上旧宿主正把会话交给别人时报忙，不再报失败。
- 预览栏的编辑器给 Makefile 上语法高亮。

### 性能

- 编辑器不带 Kotlin 和 Swift 的语法包，可执行文件小了约 10 MB。

## English

### Features

- **Edit code right in the preview**: Text files open in a code editor with completion, hover docs, go to definition and diagnostics from language servers. Servers start per git repository, and projects on SSH hosts get them too, running on that host. ⌘D adds the next occurrence to the selection.
- **Preview beside the terminal**: Drag a file tab to an edge of the terminal area to dock the preview on that side; drag it back to the title bar or the sidebar toggle to cover the terminal area again.
- Diff tabs have an Edit File button that opens the file with the line you were viewing in the diff centered; jumping to a line from search results and similar places centers it too.
- Files dragged in from Finder or opened with Open With open in the editor; on Linux and Windows, Open With and the context menu open files and folders in Runode.
- **Reorganized sidebar**: Tasks sit under the search box, leaving only Phone and Settings at the bottom; single-workspace projects collapse to one row and host groups are clearer; projects show an icon you can replace with a local image from the context menu, dimmed when no terminal is open and with a blinking dot while waiting for an answer; the agent icon sits left of the branch name.
- Your phone also gets a notification when an agent finishes.
- The commit graph's context menu can undo a commit and undo a push.

### Fixes

- Unpushed commit counts show for projects that aren't current in the sidebar and in the status bar for workspaces without git status; switching workspaces scrolls its row into view; sidebar spacing and alignment tidied up.
- Push notifications for questions show only the question, without earlier output or the tab bar.
- After the phone reconnects, the terminal size keeps following the phone's screen.
- Text from external dictation tools no longer turns into "a" in the terminal.
- Chinese file names no longer print as escaped bytes in terminals on remote hosts.
- Untracked file names in changes sent to AI for commit messages are no longer escaped.
- On Windows, empty and relative PATH entries are skipped when looking for curl.exe; curly quotes inside PowerShell single-quoted strings are doubled too.
- A new host that meets an old host handing sessions to someone else reports busy instead of failing.
- The preview editor highlights Makefiles.

### Performance

- The editor no longer bundles Kotlin and Swift grammars, making the executable about 10 MB smaller.
