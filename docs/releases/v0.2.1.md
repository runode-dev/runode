## 中文

### 新功能

- **跨网络连接更稳**：桌面、iOS 和 Android 连别的电脑时每台电脑各用一把 iroh 私钥并复用端点，Android 不再对外发布自己的地址。
- 看板的 CI 巡检在运行还没跑完、已有 job 失败时就开任务，不必等整轮跑完。
- 浅色卡片样式下外框调深，卡片和面板分得更清楚；Runode Light 调色板在浅底上更易读。

### 修复

- 设置页里已经加过 SSH 主机或配对过电脑后，仍能再添加。
- macOS 27.2 上拖自绘标题栏移动窗口不再常常拖不动。
- Claude Code 放到后台的 shell 全是在监听端口的服务（比如开发服务器）时，不再一直显示在干活。
- 辅助工具（VoiceOver 等）能读到、按到桌面上更多界面：标题报成标题，设置里的选择器按列表读，预览里的 Markdown 表格按行读、链接和表格的位置对得上。
- 远程桌面：画面帧号跳得很远时不再卡住，按键注入出错时照样松开按键，限住观看端发来的滚动量，连接出错时不再占着连接名额。
- 宿主升级接手时不再把正在开的看板任务开两次；推过「没做成」的任务好转后撤掉那条通知。
- SSH 远端每次连上都核对装好的 runode；装宿主服务时认得出带引号的 `SSH_AUTH_SOCK`。
- 前台是 fish 时往终端里打的路径按 fish 的规矩加引号；`runode send` 读完 stdin 再连上会话。
- 文件树跨卷移动文件夹、复制和覆盖写文件时保留权限和 ACL；文件名里的非 UTF-8 字节不再丢失。
- Makefile 等文件里有非 UTF-8 字节时，命令列表不再整份消失。
- 远程访问和宿主几处收包、请求加上上限；下载语音识别模型时不读 `~/.curlrc`；升级依赖，修掉安全公告。

### 性能

- 列目录时排序更快。

## English

### Features

- **More reliable cross-network connections**: The desktop, iOS and Android apps use one iroh key per computer and reuse the endpoint when connecting to other computers; Android no longer publishes its own address.
- The kanban CI patrol opens a task as soon as a job fails, without waiting for the whole run to finish.
- Borders are darker in the light card style so cards and panels stand apart; the Runode Light palette is easier to read on light backgrounds.

### Fixes

- Settings still lets you add another SSH host or paired computer after the first one.
- Dragging the custom title bar to move the window works reliably again on macOS 27.2.
- Claude Code no longer shows as working forever when all its background shells are listening servers such as dev servers.
- Assistive tools such as VoiceOver can read and use more of the desktop UI: headings are announced as headings, setting pickers read as lists, and Markdown tables in the preview read row by row with links and tables at the right positions.
- Remote desktop: no longer freezes when frame numbers jump far ahead, releases keys when key injection fails, limits scroll amounts from the viewer, and frees its connection slot when a connection fails.
- A host upgrade no longer starts a kanban task twice while it is being opened; a "didn't succeed" notification is withdrawn once the task recovers.
- SSH remotes verify the installed runode on every connection; installing the host service handles a quoted `SSH_AUTH_SOCK`.
- Paths typed into the terminal are quoted the fish way when fish is in the foreground; `runode send` reads all of stdin before connecting to the session.
- Moving folders across volumes, copying and overwriting files keep permissions and ACLs; non-UTF-8 bytes in file names are preserved.
- Commands no longer disappear entirely when a Makefile or similar file contains non-UTF-8 bytes.
- Size limits on several remote-access and host inputs; speech model downloads ignore `~/.curlrc`; dependencies upgraded to fix security advisories.

### Performance

- Faster directory listing sort.
