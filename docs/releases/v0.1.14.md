## 中文

### 新功能

- **发布 Windows 安装包**：`Runode-<版本>-windows-x86_64-setup.exe` 装到当前用户的目录，不需要管理员权限，并把命令行 `rn` 加进 PATH。安装包用自签名证书签名，首次运行时 SmartScreen 会警告。
- **Windows 上支持自动更新**：新版本的安装包要和已装的是同一份证书签的才会装上；更新时终端会话会随之结束。
- 发布文件改成统一的 `Runode-<版本>-<系统>-<架构>` 命名，macOS 只发 dmg、不再另发 zip，也没有不带版本号的副本；安装脚本和自动更新都从 dmg 里取 app。

### 注意

- 0.1.13 及更早的版本不能自动更新到这一版（它们按旧格式下载 zip），请到[发布页](https://github.com/runode-dev/runode/releases/latest)下载 dmg 或重新跑安装脚本装一次。

## English

### Features

- **Windows installer**: `Runode-<version>-windows-x86_64-setup.exe` installs per user without administrator rights and adds the `rn` command line to your PATH. It is signed with a self-signed certificate, so SmartScreen warns on the first run.
- **Auto-update on Windows**: a new installer is only run if it is signed with the same certificate as the installed app; terminal sessions end during an update.
- Release files now follow one naming scheme, `Runode-<version>-<system>-<arch>`; macOS ships only the dmg, with no separate zip and no unversioned copies, and both the install script and auto-update take the app from the dmg.

### Notes

- Versions 0.1.13 and earlier cannot auto-update to this release (they download a zip in the old format); download the dmg from the [releases page](https://github.com/runode-dev/runode/releases/latest) or run the install script again.
