## 中文

### 需要注意

- **AI 写提交说明只内置 Claude、Codex、Pi 和 OMP**：提示词里的改动和以前的提交说明可能夹带别人写的指令，agent 要是能读文件、跑命令，就可能被诱导把本机的密钥写进提交说明，或者执行命令。OpenCode、Amp、Cursor、Kimi、Muse、DeepSeek Harness、GitHub Copilot 和 Antigravity 关不掉这些工具，不再内置；存着它们的预设会报错说明原因，请从 Git 面板菜单里的「生成提交说明」改选别的 agent，或者自己写命令（自己写的命令在仓库目录里跑，不会替它关工具）。
- **Codex 写提交说明时不再读 `~/.codex/config.toml`**：这样才能挡住那里配的 MCP 服务器，同时关掉了它执行命令、联网和看图的工具。那里配的模型和服务商这时不生效，要换模型请在对话框的 CLI 参数里写 `-m`；需要较新的 Codex，旧版本会报不认识的选项。

### 新功能

- **SSH 远端主机**：新建工作区时可以先选主机，Runode 调系统的 OpenSSH 连过去，需要时自动装好 runode，断线后自动接回；远端的终端、文件树（搜索、新建、改名、移到回收站）、Git 面板和预览都直接读写那台机器，macOS、Linux 和 Windows（包括 ARM64）远端都支持。
- **远端开发更顺手**：在远端终端里粘贴截图或拖进文件，会先传到那台主机；⌘ 点文件在预览栏打开，点开 localhost 网址会自动把端口转到本机。状态栏显示连接状态和延迟，并列出远端端口，可以转到本机或停止转发。文件树能用 VS Code、Cursor 和 Zed 远程打开项目。设置里新加 SSH 主机页，可以起显示名、清理旧版本；另有新配置项 `ssh-program`、`ssh-control-persist` 和 `ssh-restore-on-launch`。
- **配对另一台电脑**：远程访问现在也能配对别的电脑上的 Runode，复制配对链接或在新建工作区时粘贴即可。配好后，那台电脑的终端、文件树、Git、预览、端口转发、远程桌面和传文件都能像远端主机一样使用，断了会自己重连；设备列表分开显示电脑和手机。
- **远程桌面能看的更多**：桌面经 SSH 或配对，可以查看并操作 macOS、Windows 和 Linux 远端的桌面，Linux 电脑也能当被看的一端。可以调清晰度和分辨率、记住密码，画面可以走 UDP。浮动的远程桌面能吸附到右侧面板，跟着那台主机的工作区走；没有可用显卡的 Windows 改用软件编码。
- **远程桌面停下时说清原因**：远程桌面停下或看不了时，桌面和手机都会说明原因和怎么办，断开后提示下面有「重新连接」按钮。
- **侧栏按主机分组**：工作区按主机分组，项目和分支挤在一行显示。组头按 macOS、Linux、Windows 画系统图标，并叠上连接状态点；有主机没连上时，状态栏上会亮起提示点。
- **新建标签菜单**：新建标签改成「+ | ⌄」分体按钮，菜单里能直接起工作区所在主机上装着的 agent，也能按序号开 shell；Windows 上还能挑用哪个 shell。
- **浮动分屏**：分屏可以浮到别的分屏上面，按停靠回到原位；浮动的终端还能拖出窗口，变成单独的终端窗口。
- **命令运行状态**：从命令菜单跑的命令还没结束时，分屏标题前会转圈，标题写命令名；再跑同一条命令时复用已经开着的终端。
- **文件标签并入标题栏**：从文件树打开的文件以标签显示在标题栏里，直接就能编辑；关掉或退出时如果有没存的修改，可以先保存。
- 终端、终端标签和侧栏工作区都有了右键菜单，标签的右键菜单能关掉其他标签和右侧的标签。
- 终端翻回回滚历史时，右边会显示位置条，右下角有「回到最新」。
- Windows 上也能设成登录时打开 Runode；Windows 和 Linux 上文件树能把文件移到回收站；Linux 上窗口改用自己画的标题栏和窗口按钮。
- Git 面板开着时会定时在后台抓取远端。快捷键设置页加了筛选框。文件树里并成一行的目录，每一段都能单独选中、右键、新建和改名。防止睡眠的选择重启后照样生效。

### 修复

- AI 写提交说明读改动时，不再执行仓库配置的过滤器。
- Windows 上 agent 的输入、配色、复制和 ConPTY 更稳定。状态栏的资源、端口和防睡眠都能用了，界面语言跟随系统，程序名显示为 Runode，也不再带 .exe。
- Windows 上，网络盘和 U 盘里的文件不再被「移到回收站」直接永久删除。
- 缩放、全屏、最小化的菜单和快捷键能用了。模态对话框开着时，快捷键不再在后面开终端，也不再关掉底下的终端。
- 终端里的 Windows 路径整个认成一个链接；写满一行的网址不再接上下一行的输出。
- 在选中的文字上用输入法组字，不再先报删掉了选中的内容；密码框不再交给输入法；Linux 和 Windows 上 Alt+Shift+字母不再吞掉 Alt，输入框里按 Ctrl 能按词移动和删除，预览栏的编辑器能用 Ctrl+S 保存。
- macOS 上从手机输入的文字带上真实键码，在虚拟机和密码框里不再都变成 a。
- Mac 上没装命令行工具时，不再因为调 git 弹出安装框；本机没装 git 时，Git 面板会说明怎么装。
- 辅助工具能拖滚动条、翻页，也能按只在悬停时露出的按钮；Windows 上能往密码框里填字。快捷键设置里，读屏能听出每个按钮属于哪个动作。
- 菜单放不下时会自动加宽，弹出位置在按钮下面，开着时悬停提示不再盖在上面；子菜单里用键盘上下选时，选中的项会滚进视野。
- 默认窗口里能放下看板的四列。新建任务找不到 agent 时就地说明，任务和定时对话框填错时焦点会跳到要改的那一栏；中文界面的定时里一周从周一排起。
- 编辑一个没改过的文件时，如果它在别处被改了，会跟着换成新内容；文件被删掉后提示文件已不在，退出时要等所有确认都过了，才丢掉没存的修改。
- 手机配对成功后自动进到这台电脑的页面；手机删掉电脑时，电脑也会忘掉这部手机；手机接硬件键盘时分得出左右 Option。
- `send --wait` 遇到 agent 没被认出在干活就直接提问时，也会停在 blocked；macOS 自带的 bash 3.2 补全目录时会补上斜杠。

### 性能

- 在后台没看着的终端大量输出时，不再拖慢界面。
- 远端项目改成监听改动，不再每隔几秒经 ssh 整个重读一遍。
- 连配对的电脑时先试上次连上的地址；往它传大文件不再每传 1 MB 就停半分钟。
- 重放 Kitty 图片和预览很长的行时占的内存更少。

## English

### Heads-up

- **AI commit messages now only build in Claude, Codex, Pi and OMP**: the changes and past commit messages in the prompt may carry instructions written by someone else, and an agent that can read files or run commands could be tricked into writing your local secrets into the commit message or running commands. OpenCode, Amp, Cursor, Kimi, Muse, DeepSeek Harness, GitHub Copilot and Antigravity can't have those tools turned off, so they are no longer built in. A saved preset for one of them now fails with a message explaining why; pick another agent under Generate Commit Message in the Git panel menu, or write your own command (your own command runs in the repository and its tools are not turned off for it).
- **Codex no longer reads `~/.codex/config.toml` when writing commit messages**: this keeps out the MCP servers configured there, and its command, web and image tools are turned off as well. The model and provider set there don't apply in this case, so put `-m` in the dialog's CLI arguments to pick a model. A recent Codex is required; older versions fail on the unknown options.

### Features

- **SSH remote hosts**: when creating a workspace you can first pick a host. Runode connects with the system's OpenSSH, installs runode there when needed, and reconnects on its own after a drop. On a remote workspace the terminal, file tree (search, create, rename, move to trash), Git panel and preview all work directly on that machine. macOS, Linux and Windows remotes are supported, including ARM64.
- **Smoother remote development**: pasting a screenshot or dropping a file into a remote terminal uploads it to that host first. ⌘-clicking a file opens it in the preview pane, and opening a localhost URL forwards the port to this computer. The status bar shows connection state and latency and lists the remote ports, which you can forward locally or stop forwarding. The file tree can open the project remotely in VS Code, Cursor or Zed. A new SSH Hosts page in Settings lets you set display names and clean up old versions, and there are new config options `ssh-program`, `ssh-control-persist` and `ssh-restore-on-launch`.
- **Pair another computer**: remote access can now pair with Runode on another computer, either by copying a pairing link or by pasting one when creating a workspace. Once paired, that computer works like a remote host for terminals, the file tree, Git, preview, port forwarding, remote desktop and file transfer, and it reconnects on its own. The device list shows computers and phones separately.
- **Remote desktop reaches more machines**: over SSH or pairing, the desktop can view and control macOS, Windows and Linux remotes, and a Linux computer can now be the one being viewed. You can set quality and resolution and save the password, and the picture can go over UDP. A floating remote desktop can dock into the right panel and follows that host's workspaces. On Windows without a usable GPU it falls back to software encoding.
- **Clear reasons when remote desktop stops**: when remote desktop stops or can't be viewed, both the desktop and the phone say why and what to do, and after a disconnect there is a Reconnect button under the message.
- **Sidebar grouped by host**: workspaces are grouped by host, with project and branch on a single line. Group headers show a macOS, Linux or Windows icon with a connection status dot, and the status bar lights up a dot when a host isn't connected.
- **New tab menu**: the new tab button is now a "+ | ⌄" split button. Its menu starts agents installed on the workspace's host directly or opens a shell by number, and on Windows you can also pick which shell.
- **Floating panes**: a pane can float above the other panes and dock back to where it was, and a floating terminal can be dragged out of the window into a separate terminal window.
- **Command status**: while a command run from the command menu is still going, a spinner shows in front of the pane title and the title shows the command's name. Running the same command again reuses the terminal that is already open.
- **File tabs in the title bar**: files opened from the file tree show as tabs in the title bar and can be edited right away, and if they have unsaved changes when you close them or quit, you can save first.
- The terminal, terminal tabs and sidebar workspaces now have context menus, and the tab menu can close other tabs or the tabs to the right.
- When scrolled back into history, the terminal shows a position bar on the right and a "Back to latest" button at the bottom right.
- Windows can now open Runode at login, the file tree on Windows and Linux can move files to the trash, and on Linux the window draws its own title bar and window buttons.
- While the Git panel is open it fetches from the remote in the background. The shortcut settings page has a filter box. In the file tree, each segment of a compacted folder row can be selected, right-clicked, created in and renamed on its own. The prevent-sleep choice now stays in effect after a restart.

### Fixes

- Reading the changes for an AI commit message no longer runs filters configured in the repository.
- On Windows, agent input, colors, copying and ConPTY are more stable. The status bar's resources, ports and prevent-sleep now work, the UI language follows the system, and the app name shows as Runode, without .exe.
- On Windows, "Move to Trash" no longer permanently deletes files on network drives or USB drives.
- The Zoom, Full Screen and Minimize menu items and shortcuts now work. While a modal dialog is open, shortcuts no longer open a terminal behind it or close the terminal underneath.
- A Windows path in the terminal is now recognized as one link, and a URL that fills a whole line no longer runs into the next line of output.
- Composing with an input method over selected text no longer first reports the selection as deleted, and password fields no longer go through the input method. On Linux and Windows, Alt+Shift+letter no longer drops Alt, Ctrl moves and deletes by word in text fields, and Ctrl+S saves in the preview editor.
- On macOS, text typed from the phone now carries real key codes, so it no longer comes out as all "a" in virtual machines and password fields.
- On a Mac without the command line tools, calling git no longer pops up the install dialog. Without git installed, the Git panel explains how to install it.
- Assistive tools can drag scroll bars, page through content and press buttons that only appear on hover, and on Windows they can fill in password fields. Screen readers can tell which action each button in the shortcut settings belongs to.
- Menus widen when their items don't fit, open below their button, and are no longer covered by hover tooltips while open. When you move up and down in a submenu with the keyboard, the selected item scrolls into view.
- The four kanban columns fit in the default window. New Task explains on the spot when it can't find the agent, and the task and schedule dialogs move focus to the field that needs fixing. In the Chinese UI, schedules start the week on Monday.
- While you edit a file that has no changes of your own, it picks up edits made elsewhere. A deleted file says it is no longer there, and quitting waits until every confirmation is answered before dropping unsaved changes.
- After pairing, the phone goes straight to that computer's page. Removing a computer on the phone also makes the computer forget the phone, and a hardware keyboard on the phone tells left and right Option apart.
- `send --wait` now also stops at blocked when the agent asks a question before it was seen working, and completing a directory in the bash 3.2 that ships with macOS adds the trailing slash.

### Performance

- Terminals you aren't looking at no longer slow down the UI when they print a lot of output.
- Remote projects now watch for changes instead of re-reading everything over ssh every few seconds.
- Connecting to a paired computer tries the last address that worked first, and sending it large files no longer stalls for half a minute every 1 MB.
- Replaying Kitty images and previewing very long lines use less memory.
