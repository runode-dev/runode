## 中文

### 新功能

- **桌面和 iOS 界面重设计**：侧栏按仓库把工作区归成项目，能拖动排序、新建工作树；工作区行和手机上的状态行用 agent 图标代替名字；agent 带编号选项的提问在桌面、看板、侧栏和手机上都能直接点选项回答，多选题画成复选框。
- **Android app**：和 iOS 一样能配对电脑、看终端、回答 agent 的提问、收推送通知。
- **看板无人值守**：任务能设时限、排队依赖和 cron，agent 做完后可自动标完成；定时可先跑检查命令、有输出才开任务，每次结果都能在记录页和 `runode todo` 里翻看；开 PR 的任务等检查都过了再结束；能立即运行一次；新建对话框里有 CI 巡检、评审新 PR 等定时模板；定时页按项目分组，卡片和记录页都用 agent logo。
- **首次启动引导页**：内置教 agent 用 runode 的 skill，一键装给 Claude Code、Codex 等各个 agent，菜单里和 `runode skill install` 也能装。
- **手机端**：能把图片和视频发给终端里的 agent；终端页长按选中文字、拷贝；设置页能选界面主题和语言，终端页的导航栏、按键栏和键盘跟着主题；远程桌面的手势重新调整，放大后双指照样滚动；没有终端的工作区收进底部一张卡。
- **语音输入消回声**：录音时消掉本机外放的声音，边放视频边说话也认得准。
- 终端支持 Kitty 图形协议按文件和临时文件传图。
- 设置页挑主题时上下键实时预览；Runode Light 改用 One Double Light 的配色；内置主题同步到 Ghostty 当前的主题库。
- 新建工作树改成对话框，关工作区时能连工作树一起删；新建任务和新建标签的 agent 菜单只列装着的。
- 桌面终端双击选词以全角中文标点为界；Git 面板悬停文件名时显示完整路径。
- 电脑上配了 APNs 密钥或 Firebase 服务账号时直接推给手机，不经中转。

### 修复

- Claude Code 有子 agent 或后台 shell 在跑时，会话照样算在干活，不会提前显示空闲；完成了的任务 agent 还在干活时，侧栏「任务」一栏也算进行中。
- 手机回答提问前先重读屏幕，题目已经变了时不再按错键。
- macOS 虚拟机里打字不再卡顿。
- 终端和手机端不再把 Kitty 图片的占位符画成方框，复制和读屏时也换成空格，复制停在图片行上的选区时不再多出空行。
- 读屏把软折开的行接回一行，窄屏上的选项不再被截断；超时的读屏不再答给下一次。
- 没开本机终端时看板也能找到 claude、codex 这些命令；workspace 里没有标签时跑命令不再崩溃。
- 免确认起 claude 时跳过它首次进入免确认模式的确认。
- 配对时直连和 Bonjour 都失败了才走 iroh，局域网里连得更快。
- iOS 远程桌面放大后拖动不再回弹，浅色主题下状态栏、快捷键栏看得清；终端页长按选字后拖动不再触发侧滑退出。
- 手机端语音输入时暂停别的 App 在放的声音，换界面语言后升级系统不丢选择。
- 完全磁盘访问已授权时引导页不再显示未授权；Windows 上 `runode skill install` 打出的路径不再混着两种分隔符。

## English

### Features

- **Redesigned desktop and iOS UI**: The sidebar groups workspaces into projects by repository, with drag-to-reorder and new-worktree actions; workspace rows and phone status lines show agent icons instead of names; numbered-option questions from agents can be answered with a click on the desktop, the kanban board, the sidebar and the phone, and multi-select questions show checkboxes.
- **Android app**: Like the iOS app, it pairs with your computer, shows terminals, answers agent questions and receives push notifications.
- **Unattended kanban**: Tasks can have time limits, queue dependencies and cron schedules, and can be marked done automatically when the agent finishes; schedules can run a check command first and only open a task when it prints something, with every result viewable on the History page and in `runode todo`; tasks that open a PR finish only after its checks pass; schedules can be run once on demand; the new-task dialog offers templates such as CI patrol and new-PR review; the Schedules page groups by project, and cards and history use agent logos.
- **First-launch onboarding**: Bundles the skill that teaches agents to use runode and installs it for Claude Code, Codex and other agents in one click; also available from the menu and `runode skill install`.
- **Phone apps**: Send images and videos to the agent in a terminal; long-press to select and copy terminal text; choose the UI theme and language in Settings, with the terminal's navigation bar, key bar and keyboard following the theme; reworked remote desktop gestures, with two-finger scrolling while zoomed in; workspaces without terminals collapse into one card at the bottom.
- **Echo cancellation for dictation**: Sound playing from this computer's speakers is removed while recording, so dictation works while a video is playing.
- The terminal supports the Kitty graphics protocol's file and temporary-file transfer.
- Arrow keys preview themes live in Settings; Runode Light now uses the One Double Light palette; built-in themes are synced with Ghostty's current theme collection.
- Creating a worktree now uses a dialog, and closing a workspace can delete its worktree too; agent menus for new tasks and new tabs list only installed agents.
- Double-click word selection in the terminal stops at full-width CJK punctuation; hovering a file name in the Git panel shows its full path.
- When the computer has an APNs key or a Firebase service account configured, it pushes to phones directly instead of through the relay.

### Fixes

- Claude Code sessions with running subagents or background shells now count as working instead of turning idle early; the sidebar's Tasks section also counts a completed task as in progress while its agent is still working.
- The phone re-reads the screen before answering a question, so it no longer presses the wrong key after the question changes.
- Typing no longer lags in macOS virtual machines.
- Kitty image placeholders are no longer drawn as boxes on the desktop or phone, read as spaces when copying and reading the screen, and copying a selection that ends on an image row no longer adds a blank line.
- Screen reading rejoins soft-wrapped lines so options aren't cut off on narrow screens, and a timed-out read no longer answers the next request.
- The kanban board finds commands like claude and codex even with no local terminal open; running a command in a workspace without tabs no longer crashes.
- Starting claude in skip-permissions mode skips its first-time confirmation.
- Pairing falls back to iroh only after both direct and Bonjour connections fail, so local connections are faster.
- iOS remote desktop no longer snaps back when dragging while zoomed in, and its status bar and shortcut bar are readable in light themes; dragging after long-pressing to select terminal text no longer triggers swipe-back.
- Phone dictation pauses audio playing in other apps, and the chosen UI language survives OS upgrades.
- Onboarding no longer shows Full Disk Access as missing when it is granted; `runode skill install` on Windows no longer prints paths with mixed separators.
