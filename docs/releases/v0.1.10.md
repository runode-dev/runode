## 中文

### 新功能

- **命令行补全**：bash、fish 和 zsh 能补全 runode 的命令和参数，候选由 runode 自己算。
- **自带 Nerd Font**：桌面 app 自带 Hack Nerd Font Mono，提示符里的图标不用另装字体也能显示。
- `macos-option-as-alt` 没写时按键盘布局决定：美式和 ABC 布局下 Option 当 Alt；苹果中文输入法开着时也默认当 Alt。
- 手机端电脑离线时不再一遍遍重试，等它上线了再连，取消能立刻停下。
- 文件树给 SQL 和数据库文件配上图标。

### 修复

- 升级时新宿主接手更稳：旧宿主卡住、刚好退出或跑在旧版 app 里时都能正确处理，结束旧宿主失败时弹框说明，关停时等 shell 退干净，不留下孤儿进程。
- 关掉最后一个且正在看的 workspace、选区只落在提示符里时按退格，都不再崩溃。
- 备用屏上程序没开鼠标上报时，滚轮当上下方向键；分屏放大时方向键也能切到相邻分屏。
- 竖条光标在第 0 列不再被裁掉，缩放后单元格尺寸重算，改配置不再重置字号；点击移光标在整行写满时算对。
- shell 集成不再盖掉 `$?`，粘贴带回车的内容也要确认；zsh 换 shell 后按键绑定不丢，vi 命令模式下重载 shell 不执行行上的命令。
- Git 页：diff 读不出时显示错误或改用 git status 列出改动，撤销提交前核对 HEAD，做到一半的合并和 cherry-pick 不撤；git 超时先温和地停，不留下 index.lock。
- AI 写提交说明不受外部 diff、颜色和 textconv 配置影响，超时后不再留下卡住的线程。
- Markdown 预览：HTML 标签和 script 的范围算对，Shift 点链接只延长选区，本地图片限总字节；文件一直在变时文件搜索照样出结果，预览不再漏掉重读。
- 文件树双击目录不再展开又收起，读不了的目录保持收起，复制失败不留半个副本。
- 设置页改快捷键时不再盖掉别的绑定，配置文件写盘失败时显示错误；配置文件去掉 BOM，循环引入按真实路径判断。
- 登录自启装失败时撤干净，并清掉旧版留下的 LaunchAgent。
- 手机端：断线时没送到的快速回复放回文本框，存储失败不丢旧配对，取消配对时删掉刚存的私钥。
- 推送的快照按轮配对，Apple 返回过大的 Retry-After 时发送线程不再崩溃。
- `runode send`、`wait` 和补全不再超出给定的时限，命令行报错里过滤控制字符。

### 性能

- 终端积压大量输出时，批与批之间让出主线程，窗口不再卡住。
- 分支列表打字时在后台检查分支名，shell 集成不再给超长命令逐字编码。
- 工作树里构建不再每次重编。

## English

### Features

- **Shell completion**: bash, fish and zsh complete runode's commands and options, with candidates computed by runode itself.
- **Bundled Nerd Font**: the desktop app ships Hack Nerd Font Mono, so prompt icons show up without installing a font.
- When `macos-option-as-alt` isn't set, it follows the keyboard layout: Option acts as Alt on US and ABC layouts, and also by default while Apple's Chinese input methods are active.
- The phone no longer keeps retrying when the computer is offline; it waits for it to come back, and cancelling stops right away.
- The file tree has icons for SQL and database files.

### Fixes

- Handing over to a new host on upgrade is sturdier: a stuck old host, one that just exited, or one running inside an older app are all handled, a failure to stop the old host is shown in a dialog, and shutdown waits for shells to exit so no orphan processes are left.
- Closing the last workspace while it's in view, or pressing Backspace with a selection only inside the prompt, no longer crashes.
- On the alternate screen without mouse reporting, the scroll wheel sends up/down arrows; arrow keys move between panes while a pane is zoomed.
- The bar cursor is no longer clipped in column 0, cell size is recomputed after zooming, editing the config no longer resets the font size, and click-to-move-cursor works on full lines.
- Shell integration no longer clobbers `$?`, and pasting text with carriage returns asks first; zsh keeps its key bindings after switching shells, and reloading the shell in vi command mode doesn't run the line.
- Git panel: when a diff can't be read it shows the error or falls back to git status, undoing a commit checks HEAD first and won't undo an in-progress merge or cherry-pick, and git timeouts stop gently without leaving index.lock behind.
- AI commit messages ignore external diff, color and textconv settings, and a timeout no longer leaves stuck threads.
- Markdown preview: HTML tags and scripts are scoped correctly, Shift-clicking a link only extends the selection, and local images are capped in total size; file search still returns results while files keep changing, and the preview no longer misses reloads.
- Double-clicking a folder in the file tree no longer expands and collapses it, unreadable folders stay collapsed, and a failed copy leaves no partial copy.
- Changing a shortcut in Settings no longer overwrites other bindings, and failures writing the config file are shown; config files have their BOM stripped and include cycles are detected by real path.
- A failed launch-at-login install is fully undone, and the LaunchAgent left by older versions is removed.
- Phone: quick replies that weren't delivered when the connection dropped go back into the text field, a storage failure no longer loses existing pairings, and cancelling pairing deletes the just-saved private key.
- Push snapshots are matched per round, and a huge Retry-After from Apple no longer crashes the sender thread.
- `runode send`, `wait` and completion no longer exceed the given time limit, and control characters are filtered out of command-line errors.

### Performance

- When a terminal has a large backlog of output, the main thread is yielded between batches so the window stays responsive.
- Branch names are checked in the background while typing in the branch list, and shell integration no longer encodes very long commands character by character.
- Builds in worktrees no longer recompile every time.
