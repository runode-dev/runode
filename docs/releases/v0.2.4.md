## 中文

### 修复

- 从访达打开 Runode 时，看板任务在用了 Git LFS 的仓库里也开得出工作树，Git 面板在这类仓库里暂存、检出也不再报找不到 git-lfs：Runode 起的 git 改用登录 shell 配好的 PATH，brew 这类目录里装的工具和钩子要的程序都找得到。经 SSH 打开的远端项目同样如此。
- 升级依赖 url，修掉安全公告 RUSTSEC-2026-0592。

## English

### Fixes

- When Runode is opened from Finder, board tasks can now create worktrees in repositories that use Git LFS, and the Git panel no longer fails to find git-lfs when staging or checking out in them: the git that Runode runs now uses the PATH from your login shell, so tools installed in places like Homebrew's directories, and the programs your hooks need, are found. Projects opened over SSH get the same fix.
- Upgraded the url dependency to fix security advisory RUSTSEC-2026-0592.
