## 中文

### 新功能

- **任务板**：铺满窗口的看板（侧栏顶上的入口或 ⌘⇧B），任务按待办、进行中、需要你、完成分列，拖到哪列就做那列的动作；开始任务时在目录或单独的工作树里开会话、把提示词交给选好的 agent，做完后干净的工作树和已合并的分支自动清掉。
- **定时任务**：按一次、每天（可选星期几）或每隔几分钟自动开任务跑 agent，错过的补跑一次，上次的还在干活时跳过。
- 命令行加 `runode todo` 和 `runode schedule`，agent 也能加任务、开始、标完成和管定时；任务有编号，`runode todo show` 看一张任务的全部内容。
- 任务做完时推送到手机。
- **diff 逐字高亮**：成对改动的行里真正改了的字垫上更深的底色，电脑和手机都有。
- app 关着时宿主也能列出、新建和改名工作区，手机上照样能开终端。
- elvish 和 nushell 有了 shell 集成。
- 终端里的程序可以用 CSI 8 t 要求改窗口尺寸。
- macOS 13 起登录自启改成系统的登录项，在系统设置「登录项」里能看到和关掉。

### 修复

- 全屏程序里快速甩滚轮不再几乎不动。
- 从程序坞或 Finder 打开时按系统语言补上 LANG，终端不再是 C 语言环境，中文和译文正常。
- 由登录自启拉起时按账户的登录 shell 开终端；fish 4 里 `read` 的提示符不再切断命令输出。
- 文件树：非法 UTF-8 的文件名不再指错文件，复制、改名不覆盖别处刚建的同名文件，删除或挪动途中切 workspace 仍更新原来那个，切换时收起开着的菜单和改名框。
- Git 页：有冲突时不再暂存全部并提交，「我方删除、对方修改」的冲突也列出来，丢弃改动和删储藏前再核对一次，`diff.context=0` 的仓库也能按块暂存。
- 提交或 AI 写说明期间改过的提交说明不再被清空或覆盖。
- diff 和预览的横向滚动能滚到最宽那行的行尾，重读后不再丢语法高亮。
- 下载 Markdown 里的网络图片不再卡死，最多等十秒。
- 切换 workspace 时关掉预览栏和菜单，状态栏固定的工作流跟着当前 workspace。
- 命令行打印的标题、路径里的控制字符换成问号，表格按显示宽度对齐中文。

### 性能

- 关掉 Metal 的 vsync 排队，程序出帧到上屏的延迟从约 21ms 降到约 11ms；滚轮发给程序时不再白白重画一帧。
- 文件树展开、定位和改完文件时在后台读目录，大目录和慢的挂载卷不再卡住窗口。
- 几万个文件时丢弃改动前的核对从几秒降到瞬间，预览和 diff 挑最宽的行不再逐行分配。
- 大图片的 diff 先查大小再读，Markdown 重读后不再留着不用的网络图片。

## English

### Features

- **Task board**: a full-window board (from the top of the sidebar or ⌘⇧B) with To do, In progress, Needs you and Done columns, where dragging a card into a column does that column's action; starting a task opens a session in its folder or a fresh worktree and hands the prompt to the chosen agent, and clean worktrees and merged branches are removed once it's done.
- **Scheduled tasks**: start an agent task once, daily (optionally on chosen weekdays) or every few minutes; a missed run catches up once, and a run is skipped while the previous one is still working.
- New `runode todo` and `runode schedule` commands let agents add, start, finish and schedule tasks too; tasks are numbered, and `runode todo show` prints everything about one.
- A push notification on the phone when a task finishes.
- **Word-level diff highlighting**: the characters that actually changed in paired lines get a deeper background, on both the computer and the phone.
- With the app closed, the host can still list, create and rename workspaces, so the phone can keep opening terminals.
- Shell integration for elvish and nushell.
- Programs in the terminal can resize the window with CSI 8 t.
- On macOS 13 and later, launch at login is a system login item, visible and switchable in System Settings › Login Items.

### Fixes

- Flicking the scroll wheel quickly in full-screen programs no longer barely moves.
- When opened from the Dock or Finder, LANG is set from the system language, so terminals are no longer in the C locale and Chinese text and translations work.
- Terminals started at login use the account's login shell; fish 4's `read` prompt no longer cuts off command output.
- File tree: file names that aren't valid UTF-8 no longer point at the wrong file, copy and rename no longer overwrite a file just created elsewhere, deleting or moving while switching workspaces still updates the original one, and switching closes open menus and rename boxes.
- Git panel: no longer stages everything and commits while there are conflicts, lists "deleted by us, modified by them" conflicts, rechecks before discarding changes or dropping a stash, and stages hunks in repos with `diff.context=0`.
- Commit messages edited while committing or while AI writes one are no longer cleared or overwritten.
- Horizontal scrolling in diffs and previews reaches the end of the widest line, and reloading no longer loses syntax highlighting.
- Downloading web images in Markdown no longer hangs and gives up after ten seconds.
- Switching workspaces closes the preview bar's and window's menus, and pinned workflows in the status bar follow the current workspace.
- The command line replaces control characters in titles and paths with question marks and aligns Chinese text in tables by display width.

### Performance

- Metal no longer queues frames for vsync, cutting the time from a program's frame to the screen from about 21ms to about 11ms; scroll events sent to a program no longer trigger a pointless redraw.
- The file tree reads directories in the background when expanding, revealing or after file changes, so large folders and slow mounts no longer freeze the window.
- Checking before discarding changes across tens of thousands of files drops from seconds to instant, and finding the widest line in previews and diffs no longer allocates per line.
- Large image diffs check the size before reading, and reloaded Markdown no longer keeps web images it no longer uses.
