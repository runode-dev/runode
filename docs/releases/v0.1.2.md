## 中文

Runode 的第一个公开版本：给 AI 编程 agent 准备的 macOS 原生终端。

### 主要功能

- **认得出 agent**：不用配置 hook，认出 Claude Code、Codex、Gemini CLI、Cursor、OpenCode、Amp 等二十多种 agent，在标签和侧栏上标出它在工作、在等你回答，还是干完了你还没看。
- **提醒与跳转**：你没在看时发通知、出提示音；`⌘⇧A` 列出所有窗口里的 agent，`⌘⌥A` 跳到下一个需要你的。
- **可编程**：自带 `runode` 命令行，能列出、读取、操作每个终端；`runode setup claude` 或 `runode setup codex` 把用法教给 agent，让它在旁边的窗格跑命令、等结果、读输出。
- **会话常驻**：打开 `terminal-host` 后，会话由独立的宿主进程持有，退出、重开、升级 app 都不断。
- **手机远程**：iOS app 在局域网里和电脑配对（`runode remote pair`），连接用 TLS 1.3 加密，能看终端、回复 agent、跑项目命令、提交 git；agent 等你回答时在灵动岛上弹出。iOS app 暂未上架，需要从源码构建。
- **项目面板**：文件树、带语法高亮的文件预览，以及能按块暂存、提交、切分支、推拉的 Git 面板。
- **更顺手的命令行**：Tab 补全带说明，提示符上的输入实时高亮，按历史给出灰字建议。
- **兼容 Ghostty**：直接读现有的 Ghostty 配置和主题。
- **原生**：Rust 写成，GPU 渲染；界面有简体中文、繁体中文和英文，支持自动更新。

### 安装

```sh
curl -fsSL https://raw.githubusercontent.com/runode-dev/runode/main/scripts/install.sh | sh
```

或者下载下面对应芯片的 dmg。Linux（x86_64、aarch64）上的安装包只有命令行和终端宿主，没有桌面界面。

## English

The first public release of Runode, a native macOS terminal built for AI coding agents.

### Highlights

- **Knows your agents**: with no hooks to configure, Runode recognizes more than twenty agents, including Claude Code, Codex, Gemini CLI, Cursor, OpenCode and Amp, and shows on tabs and in the sidebar whether each one is working, waiting for your answer, or done and not yet seen.
- **Notifications and jumping**: get a notification and a sound when you're not looking; `⌘⇧A` lists the agents in every window and `⌘⌥A` jumps to the next one that needs you.
- **Scriptable**: the bundled `runode` CLI lists, reads and drives every terminal. `runode setup claude` or `runode setup codex` teaches your agent to use it, so it can run commands in a neighbouring pane, wait for results and read the output.
- **Persistent sessions**: with `terminal-host` turned on, sessions live in a separate host process and survive quitting, reopening and updating the app.
- **Remote from your phone**: the iOS app pairs with your computer on the local network (`runode remote pair`) over TLS 1.3. View terminals, answer agents, run project commands and commit with git; when an agent is waiting for you, it pops up in the Dynamic Island. The iOS app is not on the App Store yet and has to be built from source.
- **Project panel**: file tree, syntax-highlighted file preview, and a Git panel with hunk staging, commits, branch switching, push and pull.
- **A friendlier command line**: Tab completion with descriptions, live syntax highlighting at the prompt, and history-based suggestions.
- **Ghostty compatible**: reads your existing Ghostty config and themes.
- **Native**: written in Rust and GPU-rendered; the UI is available in Simplified Chinese, Traditional Chinese and English, with automatic updates.

### Install

```sh
curl -fsSL https://raw.githubusercontent.com/runode-dev/runode/main/scripts/install.sh | sh
```

Or download the dmg for your chip below. The Linux packages (x86_64, aarch64) contain only the CLI and terminal host, without a desktop UI.
