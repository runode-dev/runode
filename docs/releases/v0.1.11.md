## 中文

### 新功能

- **看板**：任务板改名看板，侧栏顶上加新建任务、定时和看板的入口，配快捷键（按着修饰键时显示），看板入口显示需要你处理的任务数；新加记录页，能翻所有完成了的任务。
- **新建任务挑 agent**：agent 改成下拉选择，模型和强度跟着 agent 变、清单直接问 agent 本身；目录改成挑工作区；加「保存并开始」。
- 任务的终端关掉后，从看板再打开时接着 agent 上次的对话，不重跑提示词。
- runode 的 agent skill 改用 `npx skills add runode-dev/runode --skill runode -g` 安装、`npx skills update runode -g` 更新，去掉了 `runode setup` 和菜单里的「安装 agent 集成…」；用 `runode setup` 装过的请运行一次前一条命令。

### 修复

- macOS 上宿主经 launchd 拉起，Dock 上停掉终端里开的 GUI 程序时不再连带杀掉所有会话。
- 大段粘贴不再断开和宿主的连接，几个分屏一起刷屏时输出不再无限积压、内存不再一直涨。
- 安全：打开别人给的仓库时，读 git 状态和 diff 不再执行仓库里配置的过滤器和签名程序；shell 的报告口令不再能从进程环境和命令跟踪里读到；Actions 页读工作流文件不跟随链接。
- 装过 fish 补全的用户，shell 集成也能加载了；zsh 开着 nounset 时不再每个提示符都报错，bash 5.3 以下不再关掉用户开的 dotglob。
- 带着已关掉的分屏切焦点时不再崩溃；退出时的自动更新不再把新装的版本换回旧版。
- 预览栏、文件树、看板、设置页、新开终端和拖进窗口等处不再在界面线程上碰文件系统，窗口不再因此卡顿。
- 终端：设了滚动区域或原点模式时清屏不删错行，shell 集成的命令开始、结束标记不再被别家集成搅乱，`jump_to_prompt` 按数字跳 N 个提示符。
- Git 页：名字不是 UTF-8 的文件、目录、分支和子模块都处理得对，以 `-` 开头的远端分支名不当成选项，AI 写提交说明时 agent 在仓库目录里跑。
- 文件树：搜索时的操作作用在选中的结果上，改名框没改时不改名；Markdown 远程图片不再留下僵尸进程，图片按解码后的大小设上限。
- 宿主连接：重连时不再把卡住的宿主当成已退出，回话太大或超时那一刻到的回话不再断开或丢掉，交接时还在等提示符的输入由新宿主接着打。
- 手机端：配对、取消配对、删除电脑和推送登记的几处问题修好，快速回复或一次暂存的文件太多时不发、免得断开连接，连不上时每分钟重试一次。
- `runode send --wait` 不再挂住或提前返回，管道断开时静默退出；定时任务上一个 agent 还在等回答时不开新任务。
- 窗口动作和退出不再丢掉写了一半的看板任务，关掉最后一个 workspace 时照退出的规矩问后台会话。

### 性能

- 看板做成缓存的视图，后台会话列表变了只重画侧栏，窗口布局的存档改在后台写。
- 分支列表最多列 200 个分支，文件树按名字搜索只在扫描结果变了时重搜，看板定时线程不再每轮读整张任务表。

## English

### Features

- **Kanban board**: the task board is now called Kanban; the top of the sidebar has New Task, Schedules and Kanban entries with shortcuts (shown while holding a modifier), and the Kanban entry shows how many tasks need you; a new History view lists every completed task.
- **Pick an agent for new tasks**: the agent is a dropdown, the model and effort follow the agent with lists asked from the agent itself; the directory is now a workspace picker; there's a new "Save & Start".
- After a task's terminal is closed, opening it again from Kanban resumes the agent's previous conversation instead of rerunning the prompt.
- The runode agent skill is now installed with `npx skills add runode-dev/runode --skill runode -g` and updated with `npx skills update runode -g`; `runode setup` and the "Install Agent Integration…" menu item are gone. If you installed it with `runode setup`, run the first command once.

### Fixes

- On macOS the host is launched through launchd, so stopping a GUI app started from the terminal via the Dock no longer kills every session with it.
- Pasting a large block no longer disconnects from the host, and output no longer piles up without bound (with memory growing) when several panes are scrolling at once.
- Security: opening someone else's repository no longer runs its configured filters or signing program when reading git status and diffs; the shell's report token can no longer be read from the process environment or command tracing; the Actions page no longer follows symlinks when reading workflow files.
- Shell integration now loads for users who installed fish completions; zsh with nounset no longer errors at every prompt, and bash below 5.3 no longer turns off a user-enabled dotglob.
- Moving focus with a closed split no longer crashes, and the update applied on quit no longer swaps the new version back to the old one.
- The preview panel, file tree, Kanban, Settings, opening new terminals and dropping items onto the window no longer touch the file system on the UI thread, so the window doesn't stall.
- Terminal: clearing the screen with a scroll region or origin mode set no longer deletes the wrong lines, command start/end marks are no longer confused by other integrations, and `jump_to_prompt` jumps N prompts when given a number.
- Git panel: files, folders, branches and submodules with non-UTF-8 names are handled correctly, remote branch names starting with `-` aren't taken as options, and the agent writing AI commit messages runs inside the repository.
- File tree: actions during search apply to the selected result, and the rename field does nothing if unchanged; remote images in Markdown no longer leave zombie processes, and images are capped by decoded size.
- Host connection: reconnecting no longer mistakes a stuck host for an exited one, oversized replies or replies arriving right at a timeout no longer disconnect or get lost, and input waiting for a prompt during a handover is typed by the new host.
- Phone: several issues with pairing, cancelling pairing, removing computers and push registration are fixed; quick replies or staging too many files at once are refused instead of dropping the connection, and an unreachable computer is retried once a minute.
- `runode send --wait` no longer hangs or returns early, and the CLI exits quietly on a broken pipe; a scheduled task doesn't start a new run while the previous agent is still waiting for an answer.
- Window actions and quitting no longer lose a half-written Kanban task, and closing the last workspace asks about background sessions the same way quitting does.

### Performance

- Kanban is a cached view, changes to the background session list only redraw the sidebar, and window layout snapshots are written in the background.
- The branch list shows at most 200 branches, file tree name search only reruns when scan results change, and the Kanban scheduler no longer reads the whole task table every round.
