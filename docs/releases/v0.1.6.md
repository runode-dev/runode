## 中文

### 新功能

- **模拟器页**：右侧面板新增模拟器页，经 mobilecli 看和操作 iOS 模拟器、Android 模拟器。
- **设置铺在终端窗口里**：设置不再单开窗口，左边是页面列表，点返回或按 Esc 收起；外观页的配色换成三张预览卡，主题下拉带色块。
- **Markdown 预览**：Markdown 文件默认显示排版后的样子，照 GitHub 渲染标题、列表、任务框、表格、提示块、代码块、脚注和图片，也认 README 里常用的 HTML；标签栏上能切回源码。
- **项目命令**：能绑快捷键（`keybind = 键=run_task:名字`，添加、编辑命令的对话框里能直接录）；在标题栏菜单里点命令时默认在旁边分屏跑，配置项 `task-placement` 可选 `right`、`down` 或 `tab`。
- **标签**：卡片样式的标签不再占满标题栏，靠左排开、留出空白拖窗口；点挤在边上的标签时把它滚到正中。
- **Git 面板**：点开改动的图片时左右对比改之前和改之后；文件树右键菜单加上「添加到 .gitignore」。
- **无障碍**：终端、设置页、Git 面板、文件树、预览栏、对话框和窗口外框都能被 VoiceOver 和 CUA 这类辅助工具读到、按到。
- **手机端**：终端页按电脑上的分屏加一排标签；新开终端时有多个工作区就先挑开在哪个；跑项目命令时在旁边分屏；会话结束后盖上「已结束」印章，切回同一标签里的另一个分屏。
- **教 agent 用 runode 的 skill**：新增 `runode-simulator` skill，教 agent 在模拟器页的设备上构建、安装和测 app；`runode setup` 装的是 GitHub 上最新的 skill，app 启动时把装过的换成最新的，skill 更新不用等发版。
- 检查和下载更新时状态栏显示进度。

### 修复

- 远程访问：单独跑的宿主在 macOS 上自己担着责任进程，app 退出后局域网不再被拒；门禁只把签名不对、口令无效算作失败；手机发来的控制帧有大小上限，只发不读的手机不能让内存一直涨。
- 安全：读 git 状态时不再跟着未跟踪的符号链接去读；git 命令关掉 core.fsmonitor，打开别人的仓库不会执行它配置的脚本；网络图片的网址里有反斜杠、空白时不下载。
- 自动更新只收解压出来的真 .app，符号链接骗不过签名核对；装不上时原来的 app 不动。安装脚本中途被打断时把旧 app 放回原处。
- 覆盖写配置文件和 skill 时先写临时文件再换上，写到一半崩溃不再把文件截成空的。
- 宿主：拒绝特别大的终端尺寸；列目录、git 请求另起线程，卡住的网络挂载不再停住整条连接；升级交接时新宿主没确认就把会话接回来，shell 不再收到 SIGHUP。
- 从 Dock 退出、注销、关机时也把会话交给宿主；窗口存档读不了时挪成备份，不再被覆盖。
- 手机：打开 `runode://pair` 链接不再自动配对，要用户确认；删除电脑时先注销推送；弹出、收起键盘和改尺寸时终端不再跳动、提示符不再重复。
- git 路径按原始字节读，非 UTF-8 文件名也能暂存、丢弃；文件极多的仓库不再让手机断开。
- ⌘ 点击认得出 Claude Code 硬换行折开的路径和 `--out=路径` 这样的写法。
- Markdown 里没闭上的行内 HTML 标签不再带到后面所有段落；按 ⌘, 有时打不开设置的问题修好了。

## English

### Features

- **Simulator page**: a new page in the right panel shows and drives iOS simulators and Android emulators through mobilecli.
- **Settings inside the terminal window**: settings no longer open a separate window; pages are listed on the left, and Back or Esc closes them. The Appearance page shows three preview cards for the color scheme, and the theme picker shows color swatches.
- **Markdown preview**: Markdown files open rendered by default, following GitHub: headings, lists, task boxes, tables, alerts, code blocks, footnotes and images, plus the HTML commonly used in READMEs. A tab-bar button switches back to source.
- **Project commands**: bind them to keys (`keybind = key=run_task:name`, or record the key in the add/edit dialog). Commands picked from the title-bar menu run in a split next to the current terminal by default; `task-placement` can be `right`, `down` or `tab`.
- **Tabs**: card-style tabs no longer fill the title bar; they line up on the left and leave room to drag the window. Clicking a tab squeezed at the edge scrolls it to the middle.
- **Git panel**: changed images open as a side-by-side before/after comparison; the file tree's context menu gains "Add to .gitignore".
- **Accessibility**: the terminal, settings, Git panel, file tree, preview, dialogs and window chrome can be read and operated by VoiceOver and tools like CUA.
- **Mobile**: the terminal page shows a row of tabs for the desktop's splits; new terminals ask which workspace to open in when there are several; project commands run in a split; ended sessions get an "Ended" stamp and switch to another split in the same tab.
- **Agent skills**: a new `runode-simulator` skill teaches agents to build, install and test apps on the device shown in the simulator page. `runode setup` installs the latest skills from GitHub, and the app refreshes installed skills at startup, so skill updates no longer wait for a release.
- The status bar shows progress while checking for and downloading updates.

### Fixes

- Remote access: a standalone host on macOS is now its own responsible process, so local network access is no longer denied after the app quits; the gate counts only bad signatures and invalid pairing codes as failures; control frames from the phone are size-limited, and a phone that never reads can no longer grow memory without bound.
- Security: reading git status no longer follows untracked symlinks; git commands disable core.fsmonitor, so opening someone else's repository cannot run its configured script; network image URLs with backslashes or whitespace are not downloaded.
- Auto-update accepts only a real .app from the unpacked archive, so a symlink cannot slip past the signature check; if installing fails, the installed app is left alone. The install script puts the old app back if it is interrupted.
- Config files and skills are written to a temporary file and swapped in, so a crash mid-write no longer leaves an empty file.
- Host: oversized terminal sizes are rejected; directory listings and git requests run on their own threads, so a hung network mount no longer stalls the connection; during an upgrade handoff, sessions are taken back if the new host never confirms, and shells no longer get SIGHUP.
- Quitting from the Dock, logging out or shutting down also hands sessions to the host; an unreadable window archive is moved aside as a backup instead of being overwritten.
- Mobile: opening a `runode://pair` link no longer pairs automatically and asks for confirmation; removing a computer unregisters push first; showing or hiding the keyboard and resizing no longer make the terminal jump or repeat the prompt.
- Git paths are read as raw bytes, so non-UTF-8 file names can be staged and discarded; repositories with huge numbers of files no longer disconnect the phone.
- ⌘-click recognizes paths that Claude Code hard-wrapped and forms like `--out=path`.
- An unclosed inline HTML tag in Markdown no longer styles every following paragraph; ⌘, now reliably opens settings.
