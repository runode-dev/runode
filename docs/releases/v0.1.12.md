## 中文

### 新功能

- **新建任务改成看板里的一页**：不再弹框，左边列模板，点一个就填好标题、提示词、免确认和工作树；内置修 issue、处理 PR 的评审和 CI、评审 PR 三个模板，带 issue 或 PR 号的另填一项；在 `~/.runode/templates` 放 `.md` 可以加自己的模板。任务还能挑 skill、自定义 agent、附件，设免确认。看板库换了新格式，旧版本留下的任务不再显示。
- **命令快捷键按项目绑定**：快捷键挪进 `tasks.json` 的 `keys`，不同项目能把同一个键给各自的命令；Makefile 和 package.json 的命令也能在命令菜单里设快捷键。原来写在配置里的 `run_task` 快捷键不迁移，要重新设一次。
- 应用菜单加上「安装 Agent Skill」，点了开一个终端用 `npx skills` 安装 runode 的 skill。
- Linux 上也能认出终端里跑的 agent，读出前台进程的名字、参数和目录。

### 修复

- 续接看板任务时接回任务自己的 Claude 对话，不再接上同一目录里另开的那场；这一版之前开始的任务续接找不到对话，重新开始一次即可。
- Linux 上宿主交接时不再崩溃。

## English

### Features

- **New tasks are a page in Kanban**: no more dialog; templates are listed on the left and fill in the title, prompt, auto-approve and worktree with one click. Built-in templates fix an issue, address a PR's reviews and CI, or review a PR, with a field for the issue or PR number; drop `.md` files into `~/.runode/templates` to add your own. Tasks can also pick skills, a custom agent and attachments, and run with auto-approve. The Kanban database has a new format, so tasks from older versions are no longer shown.
- **Per-project command shortcuts**: shortcuts moved to `keys` in `tasks.json`, so different projects can give the same key to their own commands; Makefile and package.json commands can get shortcuts from the command menu too. `run_task` shortcuts in the old config aren't migrated, so set them again.
- The app menu has "Install Agent Skill", which opens a terminal and installs the runode skill with `npx skills`.
- On Linux, agents running in a terminal are recognized and the foreground process's name, arguments and directory are read.

### Fixes

- Resuming a Kanban task reconnects to the task's own Claude conversation instead of another one started in the same directory; tasks started before this version can't find their conversation when resumed, so start them again.
- The host no longer crashes during a handover on Linux.
